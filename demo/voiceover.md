# Crime Sentinel demo: voiceover script

Video: `crime-sentinel-demo.mp4` (1:29). About 215 words, read at roughly 150 words per minute.
Each timecode marks when that line should start, matched to the on-screen action.

| Time | On screen | Voiceover |
|---|---|---|
| 0:00 | Title card | Communities that glorify violence hide behind admission questions and invite-only chats, where keyword filters can't reach. |
| 0:05 | Mission Control | Crime Sentinel sends in a governed AI research persona, powered by Meta Muse. |
| 0:09 | Searches, groups discovered | Muse plans the searches. The persona finds four groups, and skips the survivors' support space. |
| 0:14 | Admission questions, R1 block | A private group asks admission questions. The Safety Governor blocks the first draft, because it praised the attacker. |
| 0:19 | Private group feed | Once inside, Muse reads the posts and images, and rates it a glorification community. |
| 0:23 | Approval card, cursor approves | Nothing leaves the system without a human. A reviewer approves the report to Meta Integrity. |
| 0:28 | Messenger DMs | Then the gatekeeper messages: there's a chat for Friday. |
| 0:32 | R2 block | The persona's eager reply is blocked, since no commitments are allowed. A neutral reply earns the invite. |
| 0:37 | Secret group, imminent threat | Inside, a threat post is detected. The community is rated imminent threat, and an urgent report is approved. |
| 0:45 | Meta Integrity inbox | Meta Integrity receives the evidence, the policies breached, and a recommended action. |
| 0:50 | Dashboard | Every observed post then flows into the review console, which assesses content, never people. |
| 0:55 | Review queue | Each classification shows its evidence, and harmful text stays hidden until a reviewer chooses to open it. |
| 1:03 | Intelligence | GraphRAG clusters related content, and Muse summarises each community with cited evidence. |
| 1:08 | Network | The network links posts by topic, hashtag, shared image and meaning, with no person nodes. |
| 1:16 | Trends | Trends flag the anniversary countdown as an emerging topic. |
| 1:20 | Evaluation | On our test set, Muse flagged no harmless posts as harmful. A keyword filter flagged forty-five percent. |
| 1:26 | End card | Crime Sentinel: governed by code, analysed by Muse, decided by humans. |
