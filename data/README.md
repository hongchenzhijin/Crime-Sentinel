# Data

Everything in `synthetic/` is **fictional**. The events ("Ridgeview", "Harlow Station", "Millbrook"), accounts,
posts, and trends were invented for demonstration. No real platform data is included or collected.

| File | How it is made |
|---|---|
| `synthetic/posts.json` | Generated by `scripts/generate_demo_data.py` (seed 2). About 245 posts over 8 weeks, with a deliberately constructed "anniversary countdown" topic that rises in the final three weeks. Includes some Bahasa Malaysia posts and a few posts containing contact details, so redaction can be demonstrated. |
| `synthetic/topics.json` | Generated topic list. |
| `synthetic/labelled_eval_set.json` | Hand-written and hand-labelled test set, separate from the generator templates. See `docs/evaluation.md`. |

Harmful examples are deliberately non-graphic and non-operational.

To use a permitted research dataset, produce a JSON array of records that follows `docs/data-dictionary.md`,
with `source_type: "permitted_research"` and `is_synthetic: false`, and confirm that its collection and use are
permitted before loading it.
